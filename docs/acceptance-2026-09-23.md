## 已修复

- 翻译超时覆盖响应头及正文；错误响应释放连接。
- 一次翻译调用最多 8 次外部请求、并发不超过 2；备用翻译最多 4 次尝试，遇限流或额度拒绝停止继续调用该服务。
- 默认上游 HTTP 重试由 3 次改为 0；客户端取消立即重试。
- 修复首次失败无缓存时不能在恢复联网后补拉，以及页面显示事件触发重复请求的问题。
- 批量缓存读取去重并排除个性化天气；本地缓存操作分小批执行。
- Pi 媒体备用接口只在前一方案不可用时启用，不再同时请求所有备选。
- 修复服务端、测试及客户端完整类型检查错误。
- 提示条移至底部，限制手机宽度，避免覆盖导航。
- 验收脚本分开判断可用、缓存时效、中文覆盖，任何一项失败都返回非零退出码。
- 生产环境接入 Cloudflare Workers AI，采用结构化批量翻译，已核实账户为免费套餐，未升级付费、未新增 Lunes 代理服务器。
- 修复模型批量输出缺项：保留已成功的中文，只对缺项进行一次有界补译；每次翻译处理最多 6 次 AI 调用、并发 2、总等待预算 18 秒。AI 绑定调用超时后无法主动取消已发出的调用，但不继续扩大发送。
- GitHub 仓库标识符保持原样；仅标题与真实 GitHub 仓库 URL 精确对应时免于中文误报，带英文描述的标题不能借此豁免。
- 法新社增加严格核验发布方的 AFP Fact Check 新闻索引，标注“事实核查”而非综合快讯；两个原有采集请求关闭自动重试。
- 美联社、法新社所有备选都失败时返回有界状态码诊断；不泄露上游请求头、凭据或原始错误内容，不更新旧缓存的采集时间。

## 翻译修复证据

09-23 初始检测仅 13/48 来源全中文，共 786 条纯英文标题。BBC 的线上翻译失败代码为：

```text
translate.googleapis.com:http-429
translate.google.com:http-429
api.mymemory.translated.net:http-429
```

这是线上实际接口结果，不是单元测试的模拟错误。本机的两次 Google 探测返回 200，不能据此认为 Cloudflare 上也可用。

该历史问题已通过生产 Workers AI 绑定解决，不再以免费公共翻译接口作为 Cloudflare 的首选方案。后续发现 AI、彭博政治批量翻译缺项，现已修复；09-24 定向检查 AI 30 条、美联社商业 14 条、彭博政治 20 条全部为中文，无纯英文新闻标题。

中文覆盖检查主要检查中文字符和英文标题，并非逐字语义审校。产品名、机构缩写、仓库标识符可以保留原文，机器翻译仍可能有误。保留原文、来源链接及上游发布时间供核对。

## 其他边界

- 联合国新闻返回 1 条比检测时刻晚超过 5 分钟的发布时间；保留上游原始日期并在审计中标出，不伪造时间。
- GitHub Trending 没有提供文章式发布时间，报告记为未知，不拿接口更新时间代替内容发布时间。
- 限流和缓存降低应用请求负担，但不能保证 Lunes、VPN 或 Cloudflare 账户永远不会受到第三方风控或套餐限制。
- 缓存和请求合并不是跨所有 Cloudflare 数据中心的全局限流器。
